# Day 001 — 오늘 하나

해야 할 일이 많을수록 가장 중요한 한 가지를 놓치는 문제를 해결하는 설치형 모바일 웹앱입니다.

## 핵심 기능

오늘 반드시 끝낼 일 하나를 적고, 완료하면 체크합니다. 날짜가 바뀌면 이전 기록은 보관되고 새로운 하루가 시작됩니다.

## 특징

- 회원가입과 서버 없이 브라우저에만 저장
- 모바일 우선 반응형 화면
- 홈 화면 설치 지원(PWA)
- 설치 후 오프라인 사용 가능
- 키보드 및 스크린 리더 접근성 지원
- Android 홈 화면 위젯에서 할 일 확인 및 완료 체크
- 완료 전까지 잠금화면과 알림창에 고정 알림 표시

## Android 앱과 위젯

`android/`는 Android 8.0 이상을 지원하는 네이티브 앱 프로젝트입니다. Android Studio에서 해당 폴더를 열어 실행할 수 있습니다.

1. 앱에서 오늘의 한 가지를 입력하고 저장합니다.
2. 홈 화면을 길게 누르고 **위젯**을 선택합니다.
3. **오늘 하나** 위젯을 홈 화면에 추가합니다. 1×1부터 지원하며, 2×1 이상으로 키우면 글자와 완료 버튼이 더 크게 표시됩니다.
4. 위젯 오른쪽 동그라미를 눌러 완료 상태를 바꿉니다.

할 일을 저장하면 완료 전까지 고정 알림이 표시됩니다. 알림의 **완료** 버튼이나 앱·위젯에서 체크하면 고정 알림이 즉시 사라집니다. Android 13 이상에서는 처음 한 번 알림 권한을 허용해야 합니다.

[Android APK 다운로드](https://github.com/JUNHONGKIM95/daily-mini-projects/releases/latest)

Android에서 처음 설치할 때 다운로드에 사용한 브라우저의 **알 수 없는 앱 설치** 권한을 한 번 허용해야 할 수 있습니다. v1.0.1 이하 설치본은 빌드마다 서명이 달랐으므로 v1.0.2로 넘어올 때 한 번 삭제 후 재설치해야 합니다. v1.0.2부터는 고정된 배포 서명을 사용하므로 이후 버전은 앱을 삭제하지 않고 그대로 업데이트할 수 있습니다.

Android 앱 화면은 별도로 다시 그리지 않고 웹 버전과 동일한 HTML·CSS를 앱에 포함해 사용합니다. 웹과 앱의 화면 변경이 서로 어긋나지 않습니다.

위젯은 미완료 상태에서 회색, 완료 상태에서 녹색으로 바뀝니다. 체크 표시는 앱과 같은 빈 원·완료 체크 원을 사용하고, 완료한 할 일에는 취소선이 생깁니다. 할 일 글꼴도 앱과 같은 세리프 계열을 사용합니다. 잠금 화면 위젯 후보도 선언하지만 실제 노출 여부는 Android 버전과 Galaxy One UI의 잠금 화면 위젯 지원 목록에 따라 달라집니다.

> 웹앱의 **앱 설치** 버튼은 PWA를 WebAPK 또는 바로가기로 설치합니다. 앱 아이콘과 독립 실행 화면은 제공하지만 Android 네이티브 홈 화면 위젯 제공자는 등록할 수 없으므로, 위젯 사용에는 이 Android APK 설치가 필요합니다.

## 실행

```bash
python -m http.server 4173
```

`http://localhost:4173`에서 확인하세요. 서비스 워커는 `localhost` 또는 HTTPS에서 동작합니다.

## 테스트

```bash
node --test tests/model.test.mjs
```

## 기술

HTML, CSS, Vanilla JavaScript만 사용했습니다. 빌드와 외부 의존성이 없습니다.
